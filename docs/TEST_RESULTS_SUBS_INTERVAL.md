# Проверка: «+N за M дней» по фактическим ночным замерам (вариант А, t_3da0472f)

## Что меняется

Мелкая строка под числом подписчиков на главной отвечала приростом только при
базе ровно за 30 суток. По решению владельца от 28.11.2026 (вариант А) она
печатает реальный доступный интервал по фактическим датированным замерам
Telegram-бота (`getChatMemberCount`, ночной цикл 03:00 МСК):

* истории ≥8 суток → «+N за M дней», M — фактическое число дней между датами
  использованных замеров, N — фактическая разность значений;
* накоплено ≥30 суток → автоматически «+N за 30 дней» (свежайший замер и замер
  ровно на 30 суток раньше; автосмена подписи без новой задачи и без участия
  владельца);
* пропуск замера не заполняется: база — самая ранняя точка внутри окна 30 суток,
  а если в окне точек нет вовсе — самая старая имеющаяся; подсказка (hover-плашка)
  несёт реальные даты обеих крайних использованных точек;
* меньше 8 суток истории → прежнее честное «Нет сравнения за 30 дней» (не ноль,
  не подменённый старый замер);
* только фактические измерения из хранилища: ни интерполяции, ни экстраполяции,
  ни подмены приблизительными историческими данными; TGStat S+ не подключается.

### Скриншот-проверка композиции (1440 / 390)

Синтетический релиз с правдоподобными ночными точками (черновая копия, не прод),
`randreport.web serve` на loopback, реальный браузер:

* 1440 px, окно ровно 30 суток (точки 24.10–23.11, 6620→6693):
  строка `↗ +73 за 30 дней`, подсказка «Изменение подписчиков за 30 суток по
  датированным снимкам; база — снимок на 2026-10-24.»;
* 390 px, история 8 суток (точки 15.11–23.11, 6685→6693):
  строка `↗ +8 за 8 дней`, подсказка «Реальный интервал по фактическим ночным
  замерам бота: 2026-11-15 — 2026-11-23.».

Замеры в браузере: `document.documentElement.scrollWidth == clientWidth` на
обеих ширинах (1425/1425 и 390/390), элементов с атрибутом `style` — 0,
выходящих за вьюпорт элементов (`getBoundingClientRect`) — 0, нарушений
`securitypolicyviolation` — 0. Композиция главной не менялась: тот же плакат,
фото, две бумажные цифры, «ПОКРЫЛИ РАСХОДЫ», «ЧТО ПЕРЕСЫЛАЛИ», навигация —
изменился только текст мелкой строки и её подсказки. Скриншоты приложены к
карточке (`home-1440-30days.png`, `home-390-8days.png`).
