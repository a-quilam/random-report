# Правки главной по замечаниям владельца (ветка `revision/home-details`)

Отчёт по замечаниям 2–7 владельца к главной странице: сравнение живого листка с
утверждённым прототипом
`/home/agent/.hermes/attachments/random_collage_home_prototype.html`. База —
`5eec32b` («Require an exact 30-day comparison on homepage and audit public
values»); дизайн не менялся, inline `style=` не добавлялись, приватный контур не
затрагивался.

## 1. Что сделано по замечаниям

| № | Замечание | Решение |
|---|---|---|
| 2 | У строк ведомости одинаковые подсказки | У каждой строки **своя** подсказка: утверждённый `CategoryDTO.hint`, иначе нейтральная фраза из подтверждённого названия; «Прочее» перечисляет вошедшие статьи (`home_finance_approved._sources`/`_source_row`) |
| 3 | Подсказка первой строки обрезается | Подсказка — нативный `<details>` в потоке листка, а не всплывающий тултип: рваная кромка `.source-sheet` (`clip-path`) её не режет; видимое кольцо фокуса `.hint>summary:focus-visible` |
| 4 | Нет подсказок у «октябрь: N» и у строки под подписчиками | Обе мелкие строки — раскрытия `<details class="hint subline-hint">` с собственным текстом, доступны клавиатурой (`Tab`) и касанием |
| 4.1 | Мелкий шрифт и честная формулировка | Кегль поднят (13 px десктоп, 11 px узкие экраны); точная база за 30 дней → «↗ +N за 30 дней», иначе честное «Нет сравнения за 30 дней» (не ноль, не ближайший старый замер) |
| 5 | «2026-11 · данные на … · предварительно» слишком длинно | На плашке — короткое имя месяца (`_short_period`), дата снимка и «предварительно» ушли в подсказку |
| 6 | Длинная фраза про остаток | Короткое «НЕ ПОКРЫТО: N ₽» из публичной метрики `uncovered_kopecks`; при неизвестном — «НЕ ПОКРЫТО: нет данных», не ноль |
| 7 | Звёздочка ✳ вместо логотипа владельца | Логотип владельца подготовлен компактным публичным PNG без метаданных (`randreport/web/static/brand-logo.png`), рендерится в `.brand` с `alt`; без файла — прежний знак `✳` |

## 2. Файлы

* `randreport/web/home_finance_approved.py` — короткий период, подсказки строк,
  короткое примечание, `uncovered_kopecks` из публичного DTO.
* `randreport/web/approved_home.py` — подсказки мелких строк, `brand_mark`,
  `logo_url`.
* `randreport/web/home_approved.html` — `$brand_mark`, раскрытия мелких строк.
* `randreport/web/app.py` — `_brand_logo_url` (ассет в статическом контуре).
* `randreport/web/render.py` — константа `BRAND_LOGO`.
* `randreport/web/static/approved-home.css` — поток для подсказок, кольцо фокуса,
  увеличенный кегль мелких строк, размер/поворот логотипа.
* `randreport/web/static/brand-logo.png` — новый публичный ассет (157×180, RGBA,
  45 096 Б, чанки только `IHDR`/`IDAT`/`IEND`).

* `tests/test_approved_finance.py`, `tests/test_web_leaflet_composition.py` —
  обновлены под новую разметку.
* `docs/WEB.md` — разделы §9/§10.
