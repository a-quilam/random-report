### Формулы и целостность (сверх матрицы)

* Полоса покрытия 100 %: ширины сегментов не превышают бар и в сумме дают
  ровно 100 %; при покрытии >100 % отрицательных сегментов нет и реальный
  процент не срезается; процент в подписи и в таблице совпадает; при `E=0`
  «не применимо». Сегменты берутся из строк категорий компенсации (крупнейшие
  + «прочее»), а не из захардкоженных названий.
* `history` не суммирует месяцы с пропуском (февраль–ноябрь → «частичное»,
  значение `None`), год берётся из опубликованного годового отчёта
  (459 событий, 707 920 ₽ / 1 267 226 ₽, покрытие 55,9 %), исторический
  «баланс» не выводится.
* Релиз с полем вне allowlist (`account_id` в `money.json`) не рендерится:
  `ReleaseReadError`, публике отдаётся `500` без внутренних идентификаторов.

## 4. Браузер (реальный Chromium через CDP)

Живая проекция для проверки собрана **синтетическими** данными
(`python3 -m tests.dev_release <dir> --period 2025-07`: сеть не используется,
offline-транспорты), историческая плоскость — реальные опубликованные отчёты.

| Проверка | Результат |
|---|---|
| 1280×900/1250 все восемь разделов | рендерятся, ошибок консоли нет |
| 360×640 страница `/money` | `scrollWidth == clientWidth == 360` — горизонтальной прокрутки страницы нет; `.table-wrap` прокручивается |
| 390×844, 768×1024 | вёрстка целая, навигация переносится, переключатель помещается |
| Клавиатура: `Tab` от начала страницы | фокус сначала на «Перейти к содержанию», ссылка становится видимой (`left=8, top=8`), затем на бренде; `outline: solid 3px` у активного элемента |
| Переключение периода формой | `GET`-форма → `/?period=2025-01`, выбранное значение сохраняется, заголовок и данные периода совпадают |
| Полоса покрытия | подписи сегментов читаемы внутри цветных блоков («Донаты 18,4 %», «Доля с ивента 9,2 %», «Склад 2,3 %», «недостающая часть 70,1 %» до правки; после правки число в баре и в таблице совпадает) |
| Пустое состояние | `/money?period=2024-03` → «нет данных», «Опубликованных исторических агрегатов за этот период нет» |
