# Выпуск исправленного листка: одно денежное форматирование и оформление подсказок (t_e7351076)

Карточка — выпуск кода, который уже был готов на `main`, но не отдавался живым
сайтом. На боевом адресе `https://rand.185.121.13.113.sslip.io` блок «Правила
распределения подвала» печатал суммы вторым денежным форматом
(`90000.00 ₽` рядом с листковыми `90 000,00 ₽`), а правило
`.hint-disclosure` в отданном CSS отсутствовало, поэтому раскрытие подсказки
рисовалось без оформления. Причина — сайт был собран из `03e34a7`, а исправление
лежало на `main` (`0bfdfa7`, доказательства — `docs/TEST_RESULTS_HINTS_ALLOCATION.md`).

Правила категорий, карта контура и приватный store **не менялись**: версия карты
осталась `owner-categories-1`, карта не пересобиралась. Это выпуск только кода.

**Дефект самой выкладки, найденный и закрытый в том же окне.** `rsync` с
`--chmod=F640` снял бит выполнения с `deploy/randreport-backup.sh` (в git файл
`100755`), и первое в жизни срабатывание `randreport-backup.timer` в 02:00:15 CET
закончилось `status=203/EXEC` («Permission denied» на
`/opt/randreport/deploy/randreport-backup.sh`). Исправлено: режим скрипта приведён
к `0750` (как у остальных исполняемых файлов дерева), `systemctl reset-failed` +
повторный запуск -> `Result=success`, манифест копии `integrity: ok`,
проверка восстановления `usable: true`. Ночной цикл (`randreport-sync.service`) и
публичный сайт этот бит не используют — их работа дефектом не затрагивалась.

## 4. Приёмка на живом HTTPS

Адрес — `https://rand.185.121.13.113.sslip.io` (сертификат Let's Encrypt).
Ответ на `money?period=2026-11` несёт `etag: "rel_d4750c517f2bd9ff"` — тот релиз,
что проверен в п. 3 до публикации.

* **Одно денежное форматирование.** На странице `money?period=2026-11` нет ни
  одного числа вида `NNNN.NN ₽` (0 совпадений), «90 000,00 ₽» — три; в блоке
  «Правила распределения подвала»: аренда `90 000,00 ₽`, банковский платёж
  `2 500,00 ₽`, доля `10,33 ₽` из `31,00 ₽`; таблица «Расчётная аренда /
  Банковский платёж» на месте (`2026-11 | 90 000,00 ₽ | 2 500,00 ₽`).
* **Подсказки владельца.** Пять раскрытий `<details class="hint-disclosure">` с
  текстами владельца («За газировку», «Закрытые мероприятия», «Доля с ивента»,
  «Сбор», «Расходники»); у каждого `summary` `aria-label="Подсказка: <имя>"`.
  Раскрытие оформлено: `summary` — контрол с точечным подчёркиванием, текст в
  `.hint-text`. `Tab` доводит до `summary` (позиция 15 в порядке обхода),
  обводка фокуса `3px solid` (`:focus-visible` срабатывает), `Space` и `Enter`
  раскрывают, касание на 390 px раскрывает тот же элемент; дерево доступности
  отдаёт пять узлов `DisclosureTriangle` с именами «Подсказка: …».
* **Ответы и безопасность.** Восемь страниц (`/`, `/money`, `/events`,
  `/community`, `/support`, `/chronicle`, `/reports`, `/methodology`), `/reports/2026-11`,
  четыре `/api/public/*`, `categories.csv`, `robots.txt`, `healthz` — все `200`;
  `http://` -> `https://` — `308`. `Content-Security-Policy` **не ослаблен**:
  `default-src 'none'; style-src 'self'; img-src 'self' data:; base-uri 'none';
  form-action 'self'; frame-ancestors 'none'` — `script-src` не добавлен, на
  страницах нет ни одного `<script>` и ни одного инлайнового `style=`;
  `X-Content-Type-Options: nosniff`, `X-Frame-Options: DENY`,
  `Referrer-Policy: strict-origin-when-cross-origin`,
  `Strict-Transport-Security: max-age=31536000`.
* **Раскладка.** Горизонтальной прокрутки нет ни на одной из восьми страниц на
  1440, 390 и 320 px (`scrollWidth == clientWidth` во всех 24 замерах).
* **Проверка боевого каталога.** `RANREPORT_RELEASE_DIR=/var/www/randreport
  python -m randreport.web check --db /nonexistent` -> `pages_checked: 312`,
  `problem_count: 0`.
* **Что изменилось в данных за окно.** Единственная разница между прежним и новым
  релизом `2026-11` — счётчик подписчиков канала (6684 -> 6685); `money.json`
  совпадает целиком, кроме собственного `release_id`. Денежные суммы периода не

## 6. Границы и наблюдения

* Выпущен код `main` целиком (`e65ddfe`), а не только три файла из карточки:
  вместе с ними в `/opt/randreport` ушла уже слиянная правка стола `e65ddfe`,
  иначе дерево на сервере не совпадало бы ни с одним коммитом. Тесты обоих
  интерпретаторов (700 OK) относятся именно к этому коммиту.
* Наблюдение (не дефект выпуска, не менялось): на листке **проценты** печатались
  с точкой (`48.7`, `0.7`), а **деньги** — с запятой (`340,59 ₽`) в одной и
  той же таблице. Это прежняя сквозная манера листка (проценты приходят из DTO
  строкой), а не следствие этого выпуска; вынесено отдельной карточкой и
  **закрыто**: с коммита `f387674` боевой листок печатает `48,7 %` и `0,7 %`
  (`docs/PERCENT_FORMAT.md`, `docs/TEST_RESULTS_DOC_PERCENT.md`).
* Период `2026-11` неполный (открытый месяц) — сайт говорит это текстом
  (`completeness: partial`), архив отчётов остаётся без снимков
  (`report_snapshots: 0`), страница «Деньги» в столе видит последние 200 операций
  (окно списка). Всё это ограничения данных и прежних карточек, не этой выкладки.
