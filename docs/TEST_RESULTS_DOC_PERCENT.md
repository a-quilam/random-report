# Сверка документов с принятым правилом записи процентов

Карточка `t_e37085fe` (доски `random-report`). Повод: `docs/TEST_RESULTS_RELEASE.md`
§5 описывал строку «требуют классификации» как «3,2 % и 96,8 %», а страница
`money?period=2026-11` печатала те же числа с точкой. Решение владельца по поводу
формата — `docs/PERCENT_FORMAT.md` (вариант 2, русский вид `3,2 %` единым правилом на
границе показа); правка выполнена карточкой `t_afaaf773` (коммит `f387674` на `main`)
и выложена на боевой сайт.

Задача этой карточки — не код, а документы: привести примеры процентов к тому, что
страница **реально печатает сейчас**, и убрать расхождение «документ против
страницы».

## 3. Проверка (воспроизводимо)

```bash
# документы: примеров процента с точкой нет
grep -rnE '[0-9]+\.[0-9]+ ?%' docs/*.md      # пусто (до правки было 46 вхождений)

# документы: примеры принятого правила на месте
grep -rnE '[0-9]+,[0-9]+ ?%' docs/*.md       # примеры принятого правила (82 вхождения)

# страницы: смеси разделителей нет (на каждой поверхности — 0 вхождений)
grep -nE  '[0-9]+\.[0-9]+ %' <страница>
```

Было (до этой карточки): 46 вхождений `число.число %` в трёх файлах —
`docs/PERCENT_FORMAT.md` (25 в строках 34, 192–202, 263, 268, 293–324),
`docs/TEST_RESULTS_RELEASE_HINTS.md` (1 строка, 2 вхождения),
`docs/TEST_RESULTS_WEB.md` (2 строки, 5 вхождений).
Стало: 0. Единственная десятичная точка, оставшаяся в `docs/`, — числа машинного
слоя (`0.7`, `48.7`, `3.2`, `96.8` в DTO/JSON/CSV, `width="96.8"` в SVG) и столбец
«было» в §5/§7/§8 `docs/PERCENT_FORMAT.md`; все они записаны **без знака `%`**,
поэтому под регулярку примера процента не попадают.

Поиск выполнен на `main` `f387674` вместе с правками документов этой карточки
(коммит документации — следующий после `f387674` в `git log`).

## 5. Границы

* CI-конфигурации в репозитории нет (`.github` отсутствует), поэтому роль CI-отчётов
  играют `docs/TEST_RESULTS_*.md` — они и проверены тем же поиском.
* Скриншоты `docs/screenshots/01–16` относятся к прошлой карточке публичного сайта
  (синтетический релиз `rel_f05ac2e006667619`): на них прежний разделитель (точка) и
  прежний денежный формат (`65089.00 ₽`). Они не переснимались — это
  историческое доказательство того выпуска; примечание добавлено в
  `docs/TEST_RESULTS_WEB.md`. В сыром виде PNG текста не содержит, поэтому поиск по
  `docs/` картинки не находит.
* Отдельная, не относящаяся к формату записи разница уровней округления
  (`history.coverage_percent` — `ROUND_HALF_EVEN`, `money.share_percent` —
  `ROUND_HALF_UP`) остаётся открытой и документами не решается: значения могут
  разойтись только на …x.xx5, в текущем релизе таких нет (см. `t_afaaf773`).
