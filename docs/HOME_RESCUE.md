# Главная: перенос утверждённого HTML

Только маршрут `/` получает `home_approved.html` и `approved-home.css`. Общий `site.css`, семь других страниц, источники, системные службы и формулы в домене не меняются. `reference/approved-interactive.html` — оригинал, не входной файл сервера. В работающем приложении нет JS демонстрационного редактора, диалога фиктивных постов и перехвата ссылок.

| Элемент HTML-эталона | Привязка в публичном рендерере |
|---|---|
| `.mast > .brand, .headline, .intro-line` | Исходная разметка; тот же текст и порядок четырёх вырезок |
| `.visual` | Установленное оператором разрешённое фото; используется только альфа-силуэт эталона, без его фотографии |
| `.metric.events` | Число мероприятий выбранного периода из EventsDTO или архивного агрегата; отдельно прошлый календарный месяц |
| `.metric.subs` | Последняя публичная точка и датированная база; если интервал больше месяца, указано реальное число дней |
| `.finance` | Публичные суммы, состояние полноты, короткая разбивка; подробности остаются в «Деньгах» |
| `.trend` | Только записи с наблюдаемым числом пересылок и безопасной ссылкой; в текущей публичной проекции таких записей нет |
| `.site-nav` | Семь ссылок с периодом; единственная основная навигация |
| `.footer` | Сведения о выпуске и выбор периода под нативным `<details>`; сами подсказки листка — всплывающие плашки, не раскрытия |
| `.helpful` | Подсказки (строки ведомости, мелкие строки, подпись блока денег): плашка по наведению и фокусу, `tabindex="0"` + `data-help` |

Базовый CSS извлечён из `<style>` эталона. Восемь текстур сопоставлены с локальными файлами по содержимому, не подобраны заново. Узкие дополнения к стилю обслуживают фото, недоступное значение, клавиатуру и ширины финансовой полосы без inline-стилей. Исходные PNG заказчика не перезаписываются. Для сопоставления геометрии нужны отдельные пары скриншотов из одного браузера; у приложенного десктопного PNG есть панель браузера, мобильный PNG охватывает всю страницу, а не одно окно.
