# А дорог ли РанДом?
Публичный код сайта отчётности РанДома Культуры. Здесь нет рабочей базы, секретов, закрытых первоисточников или истории внутренней разработки. Публикация кода не означает запуск боевого сайта.

Проверка публичных страниц без внешних API: `python -m randreport.web check`. Архив опубликованных агрегатов содержит ссылки на оригиналы. Оперативные финансы обновляются отдельно от веб-процесса; он не должен получать токены источников.
