# А дорог ли РанДом?

Публичный код сайта отчётности РанДома Культуры. Здесь нет рабочей базы, секретов, закрытых первоисточников или истории внутренней разработки. Публикация кода не означает запуск боевого сайта.

Проверка публичных страниц без внешних API: `python -m randreport.web check`. Архив опубликованных агрегатов содержит ссылки на оригиналы. Оперативные финансы обновляются отдельно от веб-процесса; он не должен получать токены источников.

## Сборка сайта требует явных путей

`python -m randreport.web build` без пути к частному стору (`--db` или `RANREPORT_DB`) либо без каталога релиза (`--release-dir` или `RANREPORT_RELEASE_DIR`) отказывается работать: код возврата 2 и одна строка в stderr, база не открывается и ничего не публикуется. Раньше в такой ситуации создавался пустой файл SQLite с именем `None` в текущем каталоге, а сборка отчитывалась об успехе, ничего не выпустив. Пустой (но существующий) стору допустим — отсутствующий путь нет.
