# Изменения публичного снимка

## 2026-11-22 — приём постов без webhook и публикация только утверждённых сумм

Приведён в соответствие с текущим состоянием приложения: `randreport/inbox/polling.py` (новый), `randreport/domain/finance.py`, `randreport/domain/meeting_title.py`, `randreport/ops/{cli,pipeline,publish}.py`, `randreport/store/migrations.py`, `randreport/web/release_index.py`.

* Новый приём новых постов публичного канала через `getUpdates` — без webhook и без публичного TLS-эндпоинта: сначала читается `getWebhookInfo`, и пока зарегистрирован любой webhook, опрос отказывается работать; `setWebhook`/`deleteWebhook`/`drop_pending_updates` не вызываются, поэтому чужой webhook и очередь не сбрасываются. В один вызов запрашиваются только `channel_post`/`edited_channel_post`, хранятся только посты разрешённого канала, а durable-offset продвигается лишь после записи (миграция 6). Команда: `python -m randreport.ops.cli getupdates`.
* Пока карта категорий не согласована, раздел «Деньги» публикует одну обезличенную строку на направление (`k_unclassified`, «требуют классификации») вместо строки на каждую исходную категорию: неутверждённые суммы не раскрываются, а разбивка остаётся в приватном сторе.
* Пересборка периода после правки кода или карты удаляет вытесненную ревизию того же периода, а выбор релиза для периода детерминирован (текущая ревизия, иначе новейшая) — устаревшая более подробная проекция не может быть отдана.
* Правило собраний в режиме `contains` (правило владельца «в названии встречается слово», без учёта регистра) сравнивает подстроку, поэтому слово внутри слитного названия тоже считается собранием; `exact` остаётся консервативным значением по умолчанию.

## 2026-11-22 — отказ сборки без пути к базе

Приведён в соответствие с текущим состоянием приложения: `randreport/store/db.py`, `randreport/ops/publish.py`, `randreport/web/__main__.py`.

`python -m randreport.web build` теперь отказывает (код 2, одна строка в stderr) до открытия базы, если не задан путь к частному стору (`--db`/`RANREPORT_DB`) или каталог релиза (`--release-dir`/`RANREPORT_RELEASE_DIR`); неизвестный период тоже приводит к человеческому отказу вместо трассировки. `connect` принимает только настоящий путь, а публикация релиза отклоняет отсутствующий корень понятной ошибкой. Раньше сборка без пути к базе создавала в рабочем каталоге файл SQLite с именем `None` и могла завершиться кодом 0, не выпустив ничего.
